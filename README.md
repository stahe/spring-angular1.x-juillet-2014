## 📌 Présentation

Ce document propose une introduction conjointe à deux frameworks majeurs à travers la mise en œuvre d’une application **client / serveur** :

* **AngularJS 1.x** pour la partie cliente (frontend)
* **Spring 4** pour la partie serveur (backend)

Pour simplifier, les termes **Angular** et **Spring** seront utilisés dans la suite du document.

L’objectif est d’illustrer concrètement les échanges entre un client web et un serveur Java en s’appuyant sur des technologies largement utilisées dans le développement d’applications web modernes. 

---

## 🎯 Objectifs

* Comprendre l’architecture client / serveur
* Mettre en œuvre AngularJS 1.x pour le développement frontend
* Utiliser Spring 4 pour exposer des services backend
* Illustrer les échanges HTTP entre client et serveur
* Manipuler une base de données via JPA

---

## ⚙️ Pré-requis

La compréhension de ce document nécessite les connaissances suivantes :

* Niveau intermédiaire en **Java EE**
* Maîtrise de **JPA (Java Persistence API)**
* Connaissance d’une version antérieure de **Spring**
* Utilisation de **Maven** pour la gestion de projet
* Compréhension des échanges **HTTP**
* Bases en :

  * **HTML**
  * **JavaScript**

Les notions complémentaires sont introduites progressivement au fil de l’étude de cas.
